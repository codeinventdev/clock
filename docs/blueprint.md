# **App Name**: wklock

## Core Features:

- Clock Display: Display a large, clear, customizable clock on the main page.
- Clock Customization: Allow users to customize the clock's appearance (color, font, size).
- Clock Modes: Offer different clock display modes (analog, digital, text-based).
- Inspirational Quotes: Suggest inspirational quotes about time, selected via LLM-reasoning as a tool for selecting a matching quote, depending on the time.
- Responsive Design: Responsive design to adapt to different screen sizes and devices.
- Settings Page: Implement a basic settings page to save user preferences.

## Style Guidelines:

- Primary color: Dark teal (#008080) to convey sophistication and tranquility.
- Background color: Very dark desaturated teal (#0A3333) to allow the clock to stand out.
- Accent color: Pale cyan (#77D9D9) for highlights and interactive elements, providing a clear visual cue without disrupting the calm aesthetic.
- Font: 'Inter', a grotesque-style sans-serif, for clear readability.
- Clean and minimal layout with the clock as the focal point.
- Subtle transitions between clock modes and settings.
